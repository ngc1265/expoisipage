Chequea la cadena entera: DNS, sitio, API y el puente entre los dos. Funciona incluso abriendo este archivo con doble clic.

Chequeando…

Las consultas de DNS se hacen contra el resolver público de Google por HTTPS, así que ven lo mismo que vería cualquier visitante — no lo que tenga cacheado tu máquina. Si abrís este archivo con doble clic, los chequeos de API se hacen a ciegas (el navegador no deja leer la respuesta desde file://): detectan si el servidor contesta, pero no qué contesta.
